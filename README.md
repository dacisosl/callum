# Callum Board

링크, 이미지, PDF를 칼럼으로 정리하는 개인용 보드입니다. Next.js로 만들었고 Supabase(Auth, Postgres, Storage)를 사용합니다. 배포는 Vercel이 GitHub `main` 브랜치를 지켜보다가 push마다 자동으로 합니다.

- 저장소: https://github.com/dacisosl/callum
- 데이터베이스 스키마: `supabase/schema.sql`

## 주요 기능

- 여러 보드와 칼럼 생성·이름 변경·삭제
- 카드 작성·수정·복제·삭제
- 카드의 칼럼 내부 정렬, 칼럼 간 이동, 칼럼 순서 변경
- 이미지와 PDF 첨부 및 카드 타일 미리보기 (이미지, PDF 첫 페이지, 유튜브 썸네일)
- 카드를 누르면 크게 보는 뷰어 모달: 이미지 전체 화면, PDF 뷰어, 유튜브·비메오 바로 재생
- 링크 제목·설명·대표 이미지 미리보기
- 카드마다 배경 색 선택, 칼럼마다 제목 막대와 `+` 버튼 색 선택 (기본값은 모든 칼럼이 같은 색)
- 보드별 댓글 기능 켜기/끄기. 공유받은 사람은 이름을 적고 댓글을 남길 수 있고 주인은 삭제할 수 있습니다
- 보드별 글쓰기 허용 켜기/끄기. 켜면 공유받은 사람도 그 보드에 카드를 올릴 수 있습니다
- 댓글이 있는 카드는 타일에 첫 댓글이 미리보기로 보입니다
- 카드 검색, 칼럼 접기, 자동 저장, 이동·삭제 실행 취소
- 보드별 읽기 전용 공유 링크. 홈 화면에서 공유 중인 보드의 링크를 한눈에 보고 복사·중지
- 모바일 터치와 키보드 드래그 조작
- 동영상 파일 업로드는 차단되고, 유튜브·비메오 URL은 카드 뷰어에서 재생됩니다

## 로컬 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 서버 없이 화면만 확인하려면 `.env.local`에 `NEXT_PUBLIC_DEMO_MODE=1`을 넣으면 브라우저 로컬 데모 모드로 실행됩니다.

## 화면 구성

- **홈**: 내 보드 전체를 카드로 보여줍니다. 보드 검색, 새 보드, 이름 변경, 삭제를 할 수 있습니다. 공유 중인 보드가 있으면 맨 위에 "공유 중인 보드" 목록이 나타나 링크를 바로 복사하거나 공유를 중지할 수 있고, 보드 메뉴에서 링크를 새로 만들 수도 있습니다.
- **보드**: 칼럼마다 제목 막대 아래에 `+` 버튼이 있고, 새 카드는 맨 위에 추가됩니다. 왼쪽 위 로고나 보드 이름 메뉴의 "모든 보드 보기"로 홈에 돌아갑니다. 칼럼 메뉴(`…`)에서 이름과 색을 바꿉니다.
- **카드 뷰어**: 카드를 누르면 공유받은 사람이 보는 것과 같은 화면이 뜹니다. 주인에게는 오른쪽 위에 편집 버튼이 있고, 카드 메뉴의 "수정"으로 바로 편집 모달을 열 수도 있습니다. 보드의 댓글 기능이 켜져 있으면 뷰어 아래에 댓글란이 나타납니다.
- **공유 보기**: `?share=토큰` 주소로 열리며 로그인 없이 읽기 전용으로 표시됩니다. 댓글이 켜진 보드라면 댓글은 남길 수 있습니다.

## Supabase 준비

1. https://supabase.com 에서 프로젝트를 만듭니다. 리전은 `Northeast Asia (Seoul)`을 권장합니다.
2. SQL Editor에 `supabase/schema.sql` 내용을 붙여 넣고 실행합니다. 테이블, RLS 정책, 공유 조회 함수, 첨부 버킷이 한 번에 만들어집니다.
3. Authentication → Users → Add user에서 쓸 계정을 직접 만듭니다. 앱에는 로그인 화면만 있고 가입 화면은 없습니다. Providers → Email의 **Confirm email**을 켜 두었다면 메일 인증을 마쳐야 로그인되므로, 혼자 쓴다면 꺼 두는 편이 간단합니다.
4. Project Settings → API의 **Project URL**과 **anon public** 키를 `lib/supabase-config.ts`의 `defaults`에 넣습니다. 로컬에서만 다른 프로젝트를 쓰려면 `.env.local`의 `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`가 우선합니다.

anon 키는 브라우저에 노출되는 공개값입니다. 접근 제어는 `schema.sql`의 행 수준 보안(RLS) 정책이 담당합니다.

## Vercel 배포

1. https://vercel.com 에서 GitHub로 로그인하고 Add New → Project → `dacisosl/callum`을 Import 합니다.
2. Framework는 Next.js로 자동 감지됩니다. 환경 변수는 필요 없습니다. Deploy를 누릅니다.

이후 GitHub 웹에서 코드를 고쳐 커밋하면 그대로 배포까지 이어집니다.

## 무료 요금제 참고

Supabase 무료 프로젝트는 일주일간 요청이 없으면 자동으로 일시 중지됩니다. 데이터는 유지되며 대시보드에서 Restore를 누르면 1분 안에 다시 켜집니다.

## 파일 제한

- 파일당 최대 15MB (버킷 설정과 앱 양쪽에서 제한)
- 허용 형식: 이미지, PDF
- 동영상 파일은 선택 단계와 업로드 처리 단계에서 거부됩니다

## 공유받은 사람의 글쓰기

공유 대화상자의 "공유받은 사람의 글쓰기" 스위치로 보드마다 따로 켭니다. 기본값은 꺼짐이라 기존 공유 링크는 그대로 읽기 전용입니다.

- 켜면 공유 화면에도 칼럼의 `+` 버튼이 나타납니다.
- 손님은 이름, 제목, 내용, 링크를 담을 수 있습니다. 파일 첨부는 로그인한 주인만 할 수 있어 첨부 영역은 보이지 않습니다.
- 손님이 올린 카드에는 이름표가 붙어 주인이 구분할 수 있습니다. 주인은 그 카드를 여느 카드처럼 옮기고 고치고 지울 수 있습니다.
- 저장은 `add_shared_card` 함수가 맡습니다. 토큰이 맞고 글쓰기가 켜져 있으며 칼럼이 실제로 있을 때만 통과하고, 제목 120자·내용 3000자·보드당 2000장 상한이 걸려 있습니다.

주인이 보드를 열어 둔 채로 손님이 카드를 올리면, 주인 화면은 그 카드를 모른 채로 저장하다가 덮어쓸 수 있습니다. 손님 카드가 보이지 않으면 주인 화면을 새로고침하세요.

## 댓글

공유 대화상자나 보드 이름 메뉴에서 보드별로 댓글을 켜고 끕니다. 설정은 보드 데이터의 `commentsEnabled`에 저장되고, 댓글은 `card_comments` 테이블에 따로 저장됩니다.

- 보드 주인은 RLS 정책으로 자기 보드의 댓글을 읽고 쓰고 삭제합니다.
- 공유 링크로 보는 사람은 `get_shared_comments`, `add_shared_comment` 함수로만 읽고 씁니다. 두 함수는 토큰이 맞고 `commentsEnabled`가 true인 보드에서만 동작하며, 주인의 사용자 ID는 노출하지 않습니다.
- 댓글을 끄면 기존 댓글은 지워지지 않고 숨겨질 뿐이며, 다시 켜면 그대로 보입니다.
- 이미 스키마를 적용한 프로젝트라면 `supabase/schema.sql`을 다시 한 번 통째로 실행해 테이블과 함수를 추가하세요. 공유 글쓰기용 `add_shared_card` 함수도 같은 파일에 들어 있습니다.

## 공유 방식

공유 링크는 보드마다 따로 생깁니다. 공유를 켜면 그 보드에 무작위 `shareToken`이 생기고, 공유 링크(`?share=토큰`)는 `get_shared_board` 함수로 해당 보드 하나만 읽어옵니다. 공유 목록을 열거하는 경로는 없습니다. 공유를 끄거나 링크를 재발급하면 기존 링크는 더 이상 조회되지 않습니다.

공유 링크에는 만료 기간이 없습니다. 링크를 끊으려면 홈 화면의 공유 목록이나 공유 대화상자에서 공유를 중지하거나, 링크를 새로 발급해 기존 링크를 무효로 만듭니다.

첨부파일은 공개 버킷의 URL을 사용합니다. 공유를 끈 뒤에도 파일 주소를 이미 아는 사람은 계속 열 수 있습니다. 이를 막아야 한다면 버킷을 비공개로 바꾸고 서명 URL을 발급하는 구조로 바꿔야 합니다.

## 프로젝트 구조

- `app/board-app.tsx`: 보드 UI와 상호작용 전체
- `app/api/link-preview/route.ts`: 링크 메타데이터 수집 (Vercel 서버 함수로 실행). og 태그가 없으면 `link rel="image_src"`, JSON-LD, 본문 첫 이미지 순으로 찾고, 그래도 없으면 아이콘을 내려 줍니다. 화면에서는 대표 이미지가 없거나 깨지면 WordPress.com mShots 화면 캡처(`s0.wp.com/mshots`)를, 그것도 안 되면 아이콘 표지를 보여 줍니다. 캡처는 처음 요청 때 "생성 중" 그림이 먼저 오고 잠시 뒤부터 실제 화면이 나옵니다
- `lib/supabase-client.ts`: 로그인, 보드 저장·조회, 첨부 업로드
- `lib/supabase-config.ts`: Supabase URL과 anon 키
- `lib/board-types.ts`: 데이터 형식
- `supabase/schema.sql`: 테이블, RLS 정책, 공유 함수, 버킷
